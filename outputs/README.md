# Retail Sales Performance Analysis and Revenue Prediction

**Author:** Alen Aby

## Project Overview

This project analyzes retail sales transaction data using Python and explores daily revenue prediction using machine learning.

## Objectives

- Inspect and validate transaction data.
- Perform data cleaning and preprocessing.
- Analyze monthly revenue and product category performance.
- Visualize customer purchasing patterns.
- Compare regression models using MAE, RMSE and R-squared.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Visual Studio Code

## Dataset

The project uses `retail_sales_dataset.csv`, containing transaction dates, customer demographics, product categories, quantities, unit prices and total amounts.

Keep the dataset in the project root or update the file path in the notebook to match its location.

## How to Run

1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Open `retail_revenue_analysis.ipynb` in VS Code.
5. Select the project Python kernel.
6. Run the notebook cells in order.

## Outputs

The `outputs/` directory contains the analysis charts, model evaluation results and prediction results.

## Limitations

The analysis uses a limited historical dataset. Prediction results are exploratory and should be validated on additional data before being used for business decisions.
